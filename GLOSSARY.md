# MyPad

MyPad is a shared visual working surface for Pencil drawing and communication with coding agents.

## Language

**Board**:
The single working surface containing reference content and handwriting.

**Reference**:
Visual content an agent places on the board for the user to inspect or annotate.

**Ink**:
The user's editable freehand marks on the board.

**View**:
The portion of the board the user is currently looking at, determined by pan and zoom.

**Capture**:
A visual record of the current view, combining references and ink.
_Avoid_: Backup

**Backup**:
A saved copy of the complete board that can be restored with editable ink.
_Avoid_: Screenshot

**Restore**:
Replacing the current board with a previously backed-up board.
